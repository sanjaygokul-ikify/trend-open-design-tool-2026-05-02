# Contributing to Open Design Tool

## Getting Started
1. Fork the repository
2. Clone the repository: `git clone https://github.com/your-username/open-design-tool.git`
3. Install dependencies: `npm install`

## Submitting Changes
1. Create a new branch: `git branch my-branch`
2. Make changes and commit: `git commit -m 'My changes'`
3. Push changes: `git push origin my-branch`
4. Submit a pull request

## Code of Conduct
* Be respectful and considerate of others
* Keep conversations constructive and on-topic
